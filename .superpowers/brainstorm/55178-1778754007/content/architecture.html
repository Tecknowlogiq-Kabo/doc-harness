Dependency Rules for Parallel Work

  1. Core changes first — Track 1 & 2 core APIs must be done before their web counterparts
  2. Track 3 is independent — Pure UI, no core changes needed
  3. Track 4 wraps everything — Tests written alongside each track, CLI + config at the end
